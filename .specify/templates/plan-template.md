| 层 | 文件 | 职责 |

**每条都要是别人能跑的命令或能操作的步骤。** 写不出可执行验证的 plan 不合格。

| 验证项 | 怎么验 |
|-|-|
| 类型 | `npm run typecheck` |
| core 规则 | `npx vitest run tests/core/<...>` |
| 场景 / 预制体 | `game-mcp`：打开 <场景>，检查 <节点或预制体>，应看到 <结果> |
| 包体 | `bash .cursor/skills/game-build/check-size.sh` |
| 真机 | <构建 → 微信开发者工具 → 具体操作路径> |

没有场景或预制体改动时，删掉对应行，不要留空步骤。
